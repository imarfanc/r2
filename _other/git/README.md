# _other/git

Notes about how this repository uses Git: branch naming, what goes in a commit, review expectations, release and tagging steps, recovery recipes worth not rediscovering.

Prose only. Git itself is the source of truth for what changed, and `_other/CHANGELOG.md` is the record of what shipped; write something here only when it explains a convention or a procedure that neither of those can.

`_repo/skills/git-flow/` and `_repo/skills/git-commit-ascii/` are the executable versions of some of these conventions — when a note here becomes a rule an agent should follow, move it into a skill.
